# CMMC Phase II Suspension — July 13, 2026

**Status:** Phase II (C3PAO third-party assessments) SUSPENDED INDEFINITELY.
**Source:** Department of War CIO memo + Duffey implementation memo + DoW press release.
**Date:** July 13, 2026.
**Full analysis:** `https://brief.h.porb.dev/cmmc-phase2-suspension-2026-07-13.html`

## What Changed

| Status | Requirement |
|--------|------------|
| ✅ STILL REQUIRED | DFARS 252.204-7012 — Safeguarding Covered Defense Information + Cyber Incident Reporting |
| ✅ STILL REQUIRED | CMMC Level 1 (Self) — Self-assessment for FCI per FAR 52.204-21 |
| ✅ STILL REQUIRED | CMMC Level 2 (Self) — Self-assessment for CUI per NIST SP 800-171 Rev 2 |
| ✅ STILL REQUIRED | NIST SP 800-171 Rev 2 — 110 controls baseline |
| ✅ STILL REQUIRED | DOJ Civil Cyber-Fraud Initiative — False Claims Act for false self-assessments |
| ❌ SUSPENDED | CMMC Level 2 (C3PAO) — Third-party certification assessments (~$600K cost) |
| ❌ SUSPENDED | CMMC Level 3 (DIBCAC) — Government-led deep assessments |
| ❌ SUSPENDED | November 10, 2026 Phase 2 deadline |
| ❌ SUSPENDED | All CMMC waiver procedures |

## Key Directives

1. **Only self-assessments allowed.** PMs may not designate C3PAO or DIBCAC assessments. Only Level 1 (Self) or Level 2 (Self) permitted.
2. **Active solicitations must be amended.** If original package included C3PAO/DIBCAC, program offices must amend. Contracting officers must issue amended solicitations "as soon as practicable."
3. **Existing contracts must be modified.** C3PAO requirements must be removed before next option period or next administrative modification.
4. **60-day reform task force.** Report due ~September 11, 2026. SAM.gov RFI live now.

## Why It Happened

- ~120,000 small businesses needed CMMC compliance, only ~100 C3PAO assessors available. Ratio: 1,200:1.
- SBA estimated C3PAO certification cost at ~$593,800 for small firms.
- Framed as ATS (Acquisition Transformation System) Pillar 3 alignment — "maximizing acquisition flexibility through reduced regulations and process."

## What It Means for Proposals

- **For DARPA BAA submissions:** CMMC Level 2 Self-assessment posted to SPRS before proposal submission is sufficient. No C3PAO needed. Must still implement NIST 800-171 controls.
- **For any DoD contract involving CUI:** Level 2 Self is now the ceiling during the suspension period.
- **Risk:** Self-assessment must be honest — DOJ False Claims Act enforcement is active. Contractors who falsely attest face prosecution.
- **Uncertainty:** Reform task force could reinstate third-party assessments in modified form. Monitor announcements ~Sept 2026.
