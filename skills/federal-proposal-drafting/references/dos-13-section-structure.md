# DOS Cooperative Agreement Proposal — 13-Section Structure

## Origin
Derived from DFOP0018157 NOFO (July 2026) but applicable to most State Department cooperative agreement and grant proposals. The NOFO specifies 11 required items; the 13-section structure expands Project Activities into individual workstream sections for clarity when multiple mandatory lines of effort exist.

## Section Map with Word Budgets (20-page, 15pt Open Sans target)

| Section | Content | ~Words | ~Pages |
|---------|---------|--------|--------|
| **Cover/Header Block** | Org name, UEI, CAGE, address, POC, period, budget, assistance listing | 80 | 0.3 |
| **1. Proposal Summary** | Short narrative: what you propose, why it matters, who's doing it, key differentiators. Frame the threat/problem, name the solution, list all workstreams. | 350 | 1.3 |
| **2. Introduction to Organization** | Past and present operations. For new entities: frame around individual qualifications. Must include prior State/USG grants. Address for-profit constraints if applicable. Show ability to carry out program. | 600 | 2.3 |
| **3. Problem Statement** | Clear, concise, well-supported statement of the problem. Include typology, case studies, partner capacity gaps. Show domain fluency with regulatory frameworks. | 550 | 2.0 |
| **4. Goals & Objectives** | Overarching goal (1 sentence) + numbered SMART objectives per workstream. Each objective has output AND outcome indicators. | 250 | 0.9 |
| **5. Workstream A Activities** | Detailed activities, alignment with strategic objectives, methodology, deliverables, training approach, support framework. | 700 | 2.8 |
| **6. Workstream B Activities** | Technical architecture, MVP roadmap, training data strategy, pilot deployment, production scaling. Technical credibility section with specific architectures, accuracy targets, and deployment constraints. | 750 | 3.0 |
| **7. Workstream C Activities** | Needs assessment, curriculum development, institutionalization approach, transition planning. Emphasis on sustainability and indigenous capability building. | 550 | 2.2 |
| **8. Methods & Design** | Program logic model, governance structure, substantial involvement integration (for cooperative agreements), quality assurance, internal controls. | 400 | 1.5 |
| **9. Schedule & Timeline** | Phased timeline with months, activities, milestones. 4 phases × 6 months each is standard for 24-month awards. Include geographic focus by phase. | 500 | 2.0 |
| **10. Key Personnel** | Names, titles, roles, FTE%, specific qualifications mapped to program requirements. For each person: what they've done + why it matters for THIS award. | 550 | 2.0 |
| **11. Project Partners** | Sub-awardees, data providers, academic collaborators, partner-country relationships. For sub-awardees: selection criteria, past performance, separate budget reference. | 250 | 0.9 |
| **12. MEL Plan** | Indicator table (output + outcome, baseline, target, data source, frequency). Data collection methodology. Quarterly learning cycle. Independent evaluation if budgeted. | 350 | 1.3 |
| **13. Future Funding & Sustainability** | Per-workstream sustainability plan (open-source, train-the-trainer, institutionalization). Post-award commercial viability if IP provisions allow. Responsible exit strategy. | 300 | 1.1 |
| **End Matter** | Disclaimer, certification language. | 50 | 0.2 |

## Notes on Section Weighting

The evaluation criteria determine where evaluator attention lands — not the section word count:
- **Quality (30%)** → Sections 3, 5–7 (Problem + Activities) get the most scrutiny.
- **Experience (30%)** → Sections 2, 10, 11 (Organization + Personnel + Partners).
- **Cost (20%)** → Not in the narrative. Budget and Budget Narrative carry this.
- **MEL (5%)** → Section 12. Small weight but easy to score full points with a proper indicator table.
- **Long-term Impact (15%)** → Section 13. Don't phone this in — it's 3x the weight of MEL.

## Mandatory vs. Optional in Section Content

**MUST include:**
- Organization's prior State/USG grants (Section 2). Even if "none" — say so.
- ALL lines of effort / workstreams (Sections 5–7). Missing = disqualification.
- Names and roles of key personnel (Section 10).
- Indicator table with measurable targets (Section 12).

**SHOULD include:**
- Logic model in Methods section.
- Cross-workstream integration evidence.
- For-profit constraint acknowledgment if applicable.

**MAY include:**
- Cover/summary page (optional per NOFO, but recommended).
- Letters of support in Attachment J rather than in the narrative.

## Differences from Sources Sought Responses

| Aspect | Sources Sought | Full Proposal |
|--------|---------------|---------------|
| Length | 5–10 pages | 20+ pages |
| Technical depth | Capability claims | Architecture, methodology, training data, accuracy targets |
| Personnel | Summary roles | Full bios with qualifications-to-requirements mapping |
| Partners | Named only | Selection criteria, past performance, budget reference |
| MEL | Not required | Required with indicator table |
| Sustainability | Optional | Required |
