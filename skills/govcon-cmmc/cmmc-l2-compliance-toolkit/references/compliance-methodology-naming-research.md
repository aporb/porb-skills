# Compliance Methodology Naming Research
## How Leading Cybersecurity/GovCon Consulting Firms Structure and Name Their Methodologies
> Source: Hermes agent research session, July 2026. Domain knowledge synthesis confirmed via NIST CSF 2.0 extraction.

## When to Load This Reference
- Naming the phases of a compliance methodology or framework for a client deliverable
- Building a gap-to-audit lifecycle and choosing phase names that resonate with industry buyers
- Competitively positioning a compliance offering against Big 4 / CMMC RPO methodologies
- Understanding how firms differentiate their named methodologies (branded framework names, bundling strategies, measurement KPIs)
- Writing marketing or proposal language about a compliance methodology

## Quick Reference: Universal Phase Vocabulary (Ranked by Adoption)

1. **Assess** — All firms, all frameworks. Early phase (1 or 2).
2. **Implement** — All firms. Middle phase.
3. **Monitor** — All firms, RMF, CSF. Late phase.
4. **Identify** — CSF, ISO 27001, Big 4. Early phase.
5. **Remediate** — CMMC/GovCon consultants. Middle phase.
6. **Validate** — Coalfire, CMMC RPOs. Late-middle phase.
7. **Certify** — CMMC-specific. Late phase.
8. **Operate** — Big 4 advisory. Late phase (5+).
9. **Design** — Big 4 advisory. Early-middle phase.
10. **Detect** — CSF, EY, Accenture. Middle-late.
11. **Respond** — CSF, Accenture, PwC. Late phase.
12. **Recover** — CSF, Accenture, PwC. Late phase.
13. **Protect** — CSF, ISO 27001. Middle phase.
14. **Govern** — CSF 2.0 (new). Foundational/early.
15. **Discover** — Big 4, boutique firms. Very early.
16. **Scope** — CMMC, FedRAMP firms. Very early (pre-Phase 1).
17. **Maintain** — CMMC, ISO 27001. Post-certification.
18. **Improve** — ISO 27001 (Act), Big 4. Ongoing/cyclical.

## Common Modifiers
- **Readiness** — Readiness Assessment, Audit Readiness, Certification Readiness (ubiquitous in CMMC)
- **Gap** — Gap Analysis, Gap Assessment, Control Gap Analysis
- **Pre-** — Pre-Assessment, Pre-Audit, Pre-Certification
- **Continuous** — Continuous Monitoring, Continuous Compliance, Continuous Improvement
- **Mock** — Mock Assessment, Mock Audit, Mock Certification
- **Self-** — Self-Assessment, Self-Attestation

## CMMC RPO Standard Pattern (Dominant)
```
Scoping → Gap Analysis → Remediation → Pre-Assessment/Validation → Certification → Maintain/Monitor
```
Key artifact: POA&M bridging Phase 2→3. Key metric: SPRS score improvement.

## Big 4 Branded Frameworks
- **Deloitte:** Cyber Strategy Framework (CSF) — Assess → Design → Implement → Operate → Monitor. "Secure. Vigilant. Resilient."
- **KPMG:** Cyber GRC Framework — Identify → Assess → Design → Implement → Monitor → Respond. "Defensible scoring models."
- **Accenture:** Cyber Resilience — Anticipate → Fortify → Detect → Respond → Recover. AI-powered (Cyber.AI).
- **PwC:** Cyber Readiness / Digital Trust — Assess → Strategize → Transform → Operate → Assure.
- **EY:** Cybersecurity Maturity Framework — Discover → Design → Protect → Detect → Respond → Recover.

## Major Compliance Firms
- **Coalfire:** RPO + C3PAO (strict firewall). Scoping → Readiness → Remediation → Validation → Audit → Continuous Monitoring.
- **Schellman:** Pure assessor (C3PAO only, no consulting). Scoping → Readiness → Assessment → Reporting → Surveillance.

## Standards-Based Lifecycles
- **NIST CSF 2.0:** Govern → Identify → Protect → Detect → Respond → Recover (6 functions; Govern new in 2.0)
- **ISO 27001:** Plan → Do → Check → Act (PDCA)
- **NIST RMF (800-37):** Prepare → Categorize → Select → Implement → Assess → Authorize → Monitor
- **SOC 2:** Scoping → Readiness → Remediation → Type I → Observation → Type II

## How Firms Differentiate
1. **Branded methodology names** (Deloitte's "CSF" = same acronym as NIST CSF — deliberate positioning)
2. **Bundling** (advisory + implementation + managed services + audit) vs. pure assessment
3. **Technology platform** (AI-powered, cloud platform, managed service wraparound)
4. **Measurement KPIs** (SPRS scores, maturity 1-5, quantified risk $$, board-level metrics)
5. **Sector packaging** (GovCon/CMMC = "contract enabler"; healthcare = patient data; financial = SOX-integrated)

## Leatherneck-Specific Naming Suggestions
For a Leatherneck-branded compliance methodology:
- Consider military-resonant modifiers: "Reconnaissance & Scoping," "Fortification," "Sentinel / Vigilance"
- Map to NIST CSF 2.0 for instant credibility
- Use a branded acronym: e.g., "Leatherneck Compliance Lifecycle (LCL)" or "Mission Assurance Framework"
- 5-6 phases is the industry standard (balances simplicity with completeness)
