# Subcontracting & Prime Directories

Sources for finding subcontracting opportunities — the fastest path to revenue without past performance. Small businesses register on these directories; primes search them to meet subcontracting plan goals (23% statutory small business target, 3% SDVOSB target).

## Directories

| Source | URL | What It Provides | Best For |
|--------|-----|-----------------|----------|
| **SBA Subcontracting Opportunities** | sba.gov/federal-contracting/contracting-guide/prime-subcontracting/subcontracting-opportunities | Prime contractor directory with subcontracting plans and POCs | Finding primes who need SDVOSB/small business subs |
| **DoD Subcontracting Directory** | business.defense.gov/Acquisition/Subcontracting/ | Defense primes with subcontracting plans seeking small business subs | DoD subcontracting (SDVOSB helps primes hit 3% target) |
| **DOT Subcontracting** | transportation.gov/osdbu/procurement-assistance/subcontracting-with-dot | DOT primes seeking subs for transportation contracts | DOT-adjacent (FAA, FHWA, FTA) |
| **GSA Small Business Programs** | gsa.gov/small-business/programs-and-eligibility | HUBZone, VOSB/SDVOSB, WOSB, 8(a), SBIR/STTR eligibility | Understanding which set-asides an entity qualifies for |
| **GSA Open Opportunities API** | open.gsa.gov/api/get-opportunities-public-api/ | Machine-readable JSON feed of GSA opportunities | Automated monitoring (needs API key registration) |
| **FederalFiling.com** | federalfiling.com/find-government-contract-opportunities/ | Contract opportunity search engine with NAICS/set-aside/value/deadline filters | Finding active solicitations under $250K |

## Key Points

- **Registration is free** on SBA and DoD directories. Small businesses create a profile; primes search by NAICS, set-aside status, and capability keywords.
- **SDVOSB self-attestation is valuable to primes.** Primes with subcontracting plans need to hit the 3% SDVOSB target. A self-attested SDVOSB sub (like Leatherneck) helps them meet this goal without requiring SBA certification.
- **No past performance required for sub work.** Primes evaluate sub capability, not contract history. This is the fastest revenue path for new entities.
- **GSA API requires registration** at open.gsa.gov for an API key. Free, instant approval.

## Usage Pattern

1. Register entity on SBA Subcontracting Directory (links from SAM.gov profile)
2. Register on DoD Subcontracting Directory
3. Set up GSA API key for automated monitoring
4. Use FederalFiling.com for opportunity search (filter: NAICS, set-aside, value, deadline)
5. Cross-reference with SAM.gov UI search (see `sam-gov-ui-search.md`)
