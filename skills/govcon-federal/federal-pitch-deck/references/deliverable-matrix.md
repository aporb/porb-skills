# Deliverable Design Matrix

Three document types in a federal productization engagement. Each has a distinct design role.

| Document | Theme | Primary Use | Audience | Key Features |
|----------|-------|-------------|----------|--------------|
| **Pitch Deck** | Dark HARBOR (slate/card/amber) | CEO presentation, live walkthrough | Jacob (CEO), leadership team | Scroll-snap, 18-22 slides, keyboard nav, mobile/print |
| **Brief** | Ivory/clay (FAF9F5/D97757) | Reference document, due diligence | Doug, legal, compliance | Formal, 6-10 pages, sectioned, citation-backed |
| **SOW** | Ivory/clay | Contract attachment, procurement | Procurement, legal | CLIN structure, pricing table, deliverables, timelines |

## Design Tokens

### Dark (Deck)
```
--slate: #0A0A0B    --card: #141517    --text: #F1F0ED
--a: #D4A843 (amber) --b: #1A3A5C (navy)
```

### Ivory/Clay (Brief/SOW)
```
--ivory: #FAF9F5    --paper: #FFFFFF   --slate: #141413
--clay: #D97757     --oat: #E3DACC     --olive: #788C5D
```

## Voice Distinctions

| Element | Deck | Brief | SOW |
|---------|------|-------|-----|
| First-person | Yes (credentials, stories) | Limited to about/author | Never |
| Sponsor voice | Yes (Doug section) | Indirect (attribution) | Never |
| Consulting jargon | Forbidden | Minimal | None (legal text) |
| Risk disclosure | Prominent (dedicated slide) | Section | Mitigation clauses |
| Agent count | "~30" | "~30" | "approximately 30" |
